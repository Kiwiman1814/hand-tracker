# Hand Tracker

> **Just a test — not a current project.**

Hand tracking that runs entirely in the phone browser (MediaPipe Hand Landmarker).

- Tracks up to two hands and shows how much each finger is curled (0–100 %)
- Pinch thumb + index finger to pick up blocks; they slide, bounce and push each other
- Five small puzzle levels (match colours, walls, a no-hold zone, a push-only block)
- Zoom slider (real camera zoom when the phone supports it)
- 3D view: your hand as a wire mesh next to a simple robot hand that copies the pose
- Nothing is uploaded; the camera picture stays on the device

Open it: https://kiwiman1814.github.io/hand-tracker/
