# Hand Tracker

> **Just a test — not a current project.**

Hand tracking that runs entirely in the phone browser (MediaPipe Hand Landmarker).

- Tracks up to two hands and shows how much each finger is curled (0–100 %)
- Pinch thumb + index finger to pick up coloured blocks and move them around
- Nothing is uploaded; the camera picture stays on the device

Open it: https://kiwiman1814.github.io/hand-tracker/
